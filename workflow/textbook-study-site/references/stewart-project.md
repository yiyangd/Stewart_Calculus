# Stewart Calculus 项目与答案核验约定

本文件适用于用户要求沿用 Pre-Calculus 11 学习网站的 Stewart Calculus 项目。通用的覆盖、双语、逐步解析与构建规则继续适用。本项目独立于 Precalc；首次优先制作教材第 2.3 节。

## 课程来源与目录

- 教材：`James Stewart Calculus Early Transcendentals, 7th Edition 2012.pdf`。
- 参考答案：`Stewart-7E-solutions.pdf`。先核对该书对应版本、章号、节号与原式；它不是原题清单的替代来源。
- 使用 `course.json`、`content/`、`site/`、`project-docs/`、`workflow/`。将整页渲染与临时转录留在 `tmp/`；学生网站只含必要题目原图。
- 各题保留真实教材 PDF 页、可见印刷页与全部小问。答案书定位可作为额外的 `solutionSource` 元数据，不冒充教材页码。
- 稳定课程 ID 与学习进度由课程数据驱动；不要带入 `precal11-*` 的身份、发布配置或本地进度 key。

## 先确认原书习惯

原书若没有与例题一一配套的 Practice Problem，不虚构教材 Practice。可选的原创自测必须清楚标成补充练习并单列，不占教材覆盖清单。本节所有正文 Example 和节后 Exercise 及小问均需清点。例题数量、知识点数量、题量和页码以实际页面为准。

## 逐例题连接节后习题

Precalc 的网页通过共享知识点显示相关 Exercises。本项目在此基础上满足“每道例题对应课后习题”的请求：从实际题目方法建立更细的映射，不能只把同一知识点全部题号重复贴在每个例题下面。

保存一份可复核的映射清单。本项目已采用每道 Example 的 `relatedExercises` 与 Exercise 的反向 `relatedExamples`，并在 `project-docs/` 保存分类表。每条对应至少包括实际 Example ID、Exercise 题号、关系与双语理由；独立映射表也可包含下列字段：

| 字段 | 内容 |
| --- | --- |
| `exampleId` | 已存在且唯一的正文例题 ID。 |
| `conceptIds` | 对应知识点 ID。 |
| `exerciseNumbers` | 真实节后题号，必要时精确到小问。 |
| `relationship` / `relation` | 前端使用 `same-method` 与 `extension`；后者合并显示“综合与拓展”。独立表可细分综合运用与拓展，但不要加入前端未识别的枚举。 |
| `reason` / `en.reason` | 简短说明具体对应运算或思路，例如“先约去共同因子，再使用商法则”。 |
| `sourceNote` / `en.sourceNote` | 教学整理的对应；仅在原书明确指定时才称教材指定配套。 |

每道正文例题只在一个主要知识点中展示。Exercise 可以关联多个知识点或例题，但全站仍只有一个 `exercise-<number>` 条目。页面每个例题应提供可以跳到对应题目的链接；知识点底部保留全类习题链接。没有直接同型习题时如实标明，再提供相关综合或拓展题，不为了填满对应表强配。

## 教材与答案书核对

1. 先对教材渲染页独立清点和转录题干，再独立解题。
2. 到答案书对应节核对具体题号、原式、条件与答案；确认跨页、双栏和偶数题均未漏读。
3. 参考答案只有结论或省略中间步骤时，自行补足可独立理解的运算，不将答案书的简写当成完成解析。
4. 答案差异先检查转录、根号覆盖范围、变量方向、定义域与版本。若确有教材或答案书错误，用独立推导处理，在审核记录保留原文位置与理由。
5. 答案书缺某题时保留具体记录，通过独立数学核验继续完成；不得写“已核对参考答案”。

`audit.sourceReviewed` 表示原题及来源已经复核；`audit.solutionsReviewed` 表示解析已经独立复核。两者不由“答案书有这个题”或脚本通过自动推定。

## 第 2.3 节极限题的专项验收

- 应用和、差、常数倍、积、商、幂与根法则前写明条件。商法则要求分母极限非零；实数偶次根式注意定义域。
- 直接代入得到 `0/0` 只是未定式，不是答案。因式分解约分、分式整理或乘共轭后只在原函数允许的穿孔邻域中讨论。
- 区分 `f(a)` 与 `lim_{x→a} f(x)`；约去因子不把原函数缺失的点补入定义域。
- 双侧极限存在需要左右极限相同。绝对值、分段函数或跳跃题分别计算两侧；只给一个方向不回答双侧问题。
- 根式有理化写清共轭、分子分母乘法以及后续约分；复杂小问不要跳过关键展开。
- 使用夹逼定理写出实际不等式及两端相同极限；仅数值抽样或图像接近不能代替论证。
- 从给定图像读极限时保留题目原图，区别空心/实心点与每侧趋近值，不能以自行绘图替代教材证据。
- 表格或计算器近似是支持证据；可精确推导的极限优先给精确值。任何缺图、不能辨认或外部互动缺项都需明确记录。
