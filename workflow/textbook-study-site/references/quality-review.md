# 来源、数学与网页验收

## 独立覆盖清单

清单来自原书页面，不能根据已生成的 JSON 反推“期望题量”。先记录章节起止页、所有 Example/Practice/Exercise ID、每题小问和原图，再与成品对齐。原书分组范围印刷不一致时，读相邻栏与下一节边界，记录采用的范围和依据。

PDF 文本仅作辅助：上下标、负号、分数线、整个根式的覆盖范围、合成除法列及跨页的小问必须对照原图。若有讲义，记录讲义题的 Part 和页码，同时区分教材与讲义来源。

## 可读的逐步解析

每题的步骤应可独立阅读：

1. 明确要求或建立模型，记录适用条件。
2. 写出具体变形、代入、分解或计算。
3. 从结果判断解、区间、图像或结论。
4. 核对原式、端点、定义域、单位、重数或情境范围，并给出答案。

按实际题目调整步骤，不强迫简单判断题写七步，也不把复杂证明压成三个没有推导的结论。多小问题可按 (a)/(b)/(c) 分段；`subpartIds` 用于覆盖检查，不能代替小问本身的解析。

题干保留教材给出的形式。例如原式为展开多项式时，不在题干提前提取因子；变形放入步骤。翻译后逐题比对条件、严格/非严格符号、变量单位和答案。

## 数学检查按题型执行

| 题型 | 有效核验 |
| --- | --- |
| 多项式与复根 | 因子乘回原式；根代入；所有根重数之和与次数相符；共轭结论只用于实系数情形。 |
| 合成除法 | 插入缺项零系数；逐列核对乘积与加法；商乘除式再加余数等于被除式。最后一列余数也参与上下界判据。 |
| 不等式 | 从原分子、原分母独立列临界点；逐区间测试并检查每个端点、孤立零点与约分后仍禁止的值。 |
| 定义域 | 核对根号覆盖范围、分母不为零；分母里的偶次根式必须严格为正。 |
| 图题与构造 | 原图可见且不泄露答案；从确切标注读截距、重数和方向；未给比例条件时不要伪造唯一系数。 |
| 应用题 | 代数解与实际有效域取交集；检查整数、物理限制、历史年份及单位；近似值明确标近似。 |
| 证明与参数分类 | 检查全部子问、特殊参数值、退化情况与假设；区分“所有复根”和“唯一实根”。优先采用学生已经学过的方法。 |

可用符号代数工具进行精确核验，也可用独立代数推导。数值抽样只能补充，不能取代完整解集或证明。不要对来源文本使用不受控 `eval`。

保持负数平方括号：`(-8)^2` 与 `-8^2` 含义不同。区分主平方根与方程的两个解。重根须计重数，不能将不同根个数当总次数。

## 原文可能有错时

保留原题题意，通过独立计算或反例判断。若确定教材印刷错误，网页采用正确结论，审核记录保留页码、原错误、修正依据；只在学生需要理解差异时展示短注。

例如某教材将合成除法下界的交替行判据写成任意实数测试值。正测试值的交替行并不足以证明下界；教学应补上标准负测试值条件。这个例子用于说明核对假设的必要性，不是给所有学科套用同一规则。

对于打不开的互动链接、无法辨认的公式或缺图，明确哪些题没有核实。可以继续其余内容并保留草稿，不能把常见补充模型称为原题，也不能用“全量校验通过”掩盖缺项。

## 独立复核与网页检查

让复核者从原始页面独立核对关键公式和结论；不要只提供预期答案让其确认。优先复审新题型、图题、参数分支、复杂证明、符号含义和教材疑似错误。

构建时运行覆盖与结构检查，并验证内嵌 JSON 与独立 `data.json` 一致。完成代表性浏览器检查：默认英语、中文切换、题号/范围/知识点筛选、展开状态、进度与首页导航。图表在手机上可在自身容器内横向滚动，不应撑宽页面。检查原图确实加载，函数图标明所绘函数。

公开发布前扫描课程包：无源书 PDF、账户信息、凭据、本机路径或原站点 project ID。部署必须核对成功的提交或版本与实际内容一致。
