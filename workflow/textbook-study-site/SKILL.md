# 教材双语学习网站

把用户指定范围的教材变成学生可直接使用的学习网页。沿用打包的奶油色与深青色界面：知识点 → 原例题 → 配套练习 → 对应教材习题。默认英语，可切换中文；所有题目和小问都应有完整解析。

## 输入与范围

- 在 Stewart Calculus 项目中，先读 [项目与答案核验约定](references/stewart-project.md)。它补充正文例题到节后习题的逐题对应、教材与答案书定位及极限题的数学验收；通用数据合同仍适用。

- 找到教材、章节范围、可选讲义和现有网站。缺讲义时依据教材继续，来源标为教材，不虚构 Lecture。
- 新书使用独立的课程 ID、目录和学习进度；只有用户明确要求合并时才加入其他书的首页。
- 现有站点优先保留布局、地址、历史链接和用户进度。新站点可使用 `assets/frontend/`；不要对旧站点盲目运行重建工具。
- 网页制作与外部发布分开处理。沿用当前会话已授权的发布目标；新仓库、公开范围或不明确的目标不能从本 skill 推断。

## 从教材到网页

1. **先清点原文。** 识别实际章节起止页，记录真实 PDF 页及实际可见的印刷页；没有印刷页时不补造。非 PDF 使用真实页码或来源定位，不编造 PDF 页。清点每一个 Example、Practice、Exercise 和小问，包括跨页或跨栏部分；下一节的 Review Skills 不应混入本节。讲义题与教材题采用不同 ID 和清晰来源标签。将清单保存为 `coverage`，再开始写解答。
2. **压缩知识点。** 保留完成本节题目所需的定义、条件、方法和容易漏掉的限制。数量由内容决定，不固定为 7 或 8 个。原文没有正文例题的拓展知识点要明确注明来自习题。
3. **保留原题，重写步骤。** 每一步写清动作、具体运算和得到的结果；复杂题可以增加步骤。答案不能只引用其他题。题干保持原表达式与全部条件，因式分解等提示留到解析中。英文依据教材原文，中文保持同一数学含义。
4. **核对来源与解答。** 公式、图题、根号范围和多栏排版需对照渲染页目视检查。数学核验与独立复审按 [质量检查](references/quality-review.md) 执行；结构检查不能替代数学核验。
5. **装配学习页。** 每题只指定一个主要展示知识点，避免同一原题重复生成 ID；习题可以关联多个知识点。配原图、图像、符号表、合成除法等真正有帮助的视觉内容。例题默认展开，Practice 与 Exercises 默认收起。
6. **验证学生体验。** 检查全部题号和小问、英文完整性、语言切换后展开状态和筛选保留、跨页语言、独立进度、手机排版、图像载入及打印。未指定有效 `lang` 时仍默认英语，不让旧中文偏好覆盖默认。
7. **按授权发布。** 将新章节加入首页，验证部署完成和真实网址、题库与图像可访问，再报告结果。Sites 发布遵循当前 Sites 技能；GitHub Pages 使用用户指定仓库并检查对应提交的部署。工具不可用时交付本地结果并说明未完成的发布环节。

## 数据与复用工具

首次使用前端或工具前读 [数据与构建合同](references/content-schema.md)。

- `scripts/check_content.py <lesson.json>`：检查独立清点的覆盖清单、中英文字段、子题与可渲染的数据结构。
- `scripts/build_course.py --manifest <course.json> --output <site-directory>`：验证后用通用前端构建新课程，并生成同步的独立 JSON 与内嵌 JSON。原图从题目数据目录的 `assets/` 复制。
- 工具使用 Python 标准库，不要求前端安装依赖。支持直接本地打开及静态托管。
- 前端资源只含布局和功能；教材内容、课程名称、页码、题量均由数据提供。不要把本机绝对路径、原书 PDF、凭据或既有站点身份打包到公开站点。

## 批量制作与恢复

较大章节可把正文例题、连续习题段和独立复核分别交给子任务；每段各自负责来源核对和解析，主任务负责合并、覆盖检查与网页发布。小章节无需固定数量的代理。

保存来源清单、每段已完成 JSON 和审核记录。中断后从已核对的内容继续，不重做已完成章节；新的修订仅对受影响内容重新验证。整本书按章节逐批完成，避免一次生成后遗漏尾部题目。

不要把可能的模型切换写成自动配置变更。执行能力和思考档由用户选择；任务拆分与用量建议见 [模型与任务分工](references/model-use.md)。

## 完成标准

来源清单与网页全部对齐；每道原题及小问有相符的双语题干、步骤与答案；数学和来源问题已处理；首页、语言与图像检查通过。存在无法核实的原题、缺图或外部互动内容时，保留具体缺项，说明影响，不用自造模型冒充原题答案，也不宣称全量解析已完成。

最终给学生网页与首页链接，说明实际覆盖数量、默认语言和任何尚未解决的限制。若仅完成本地结果，则链接到本地入口。
